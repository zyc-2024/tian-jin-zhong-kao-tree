# 天津中考树：PE Focus

《天津中考树》的 PE Focus 更新。游戏以天津中考为背景，用增量/模组树的方式重走初中三年：语文、英语、数学理论、中考分数、经验、自动化与排行榜层层嵌套。

## 术语约定

- 树节点使用短标记：H = 历史，G = 地理，Pol = 政治，PE = 体育，Syn = 综合素质。
- 中文界面统一使用：历史、地理、政治、体育、综合素质。
- 英文层名统一使用：History、Geography、Politics、Physical Education、Synergy。
- 内部层 ID 与存档字段仍为 `His`、`Geo`、`Pol`、`PE`、`Syn`，不随显示文本变化，旧存档可以继续读取。
- 物理层（P）已在 v0.8.0 删除，不再出现在树上。

## 树形布局

```text
第一排：C   M   Eng   H   G   Pol
第二排：            E
第三排：            PE

右侧：Syn / A / Am / Exp / L / Nf
```

## v0.8.0 PE Focus

- 删除物理层（P），树上的物理训练、物理里程碑和物理成就全部移除。
- 体育层移到中考层（E）正下方，成为唯一的训练挑战层。
- 语文 / 数学 / 英语 / 历史 / 地理 / 政治全部放在第一排。
- 主科节点缩小并禁止换行，保证六门主科始终在同一行。
- 右侧 side 层下移，避免和主科节点重叠。
- 地理联动改为数学理论；综合素质联动用「数英」「体政」替换「数理」「体理」。
- 体育成就页替换原物理 / 体育成就页，原 5 个成就全部改为体育目标。
- 旧存档会自动清理物理层数据，体育层与成就数据保留。

## v0.7.1 Clarity

- 统一学科称呼：树节点使用 H / G 等短标记，中文界面使用历史 / 地理 / 政治 / 体育 / 综合素质，英文全名只用于层名和代码。
- 层提示、说明框、成就名、里程碑描述、考试交卷、分数标题和成就页签全部同步。
- 修正“文史贯通”等与联动对象不符的文本，统一为“政史贯通”。
- “中考最佳分数”和“最佳中考分数”统一写法；训练计时改为中文。
- 内部层 ID 与存档字段保持不变，旧存档可以继续读取。

## v0.7.0 Synergy

- 新增综合素质层：把各层里程碑做成 10 组跨学科联动。
- 联动包括语史、语政、语英、数英、数地、英地、史地、政史、体政、体地。
- 每对联动等级由双方层的里程碑数量决定，提供全科知识倍率。
- 综合素质层可产出综合素质，购买跨学科整合、联合教研、全面发展等永久奖励。
- 新增综合素质层里程碑和 5 个联动成就，成就页新增综合素质页签。

## v0.6.0 Achievements

- 为数学 / 计数法 / 自动化 / 经验 / 排行榜 / 语文 / 中考 / 英语的里程碑增加对应成就。
- 新增全局里程碑收集成就：10 / 30 / 50 个里程碑。
- 新增「成就达人」「成就狂人」等成就自身成就。
- 成就页新增数学 / 策略 / 自动化、经验 / 排行榜、语文 / 中考 / 英语、全局里程碑四个页签。
- 所有新成就都会增加 A 层 Goals，并与 A 层里程碑联动。

## v0.5.0 Milestones

- 为每个层级补充里程碑：语文 / 中考 / 英语 / 数学 / 计数法 / 成就 / 自动化 / 经验 / 排行榜 / 体育 / 政治 / 历史 / 地理。
- 体育 / 政治 / 历史 / 地理、数学 / 计数法 / 成就 / 自动化新增里程碑页签。
- 所有新增里程碑提供可叠加的全科知识倍率，采用加算避免数值失控。
- 里程碑达成时自动弹窗并即时生效。

## v0.4.0 历史 / 地理

- 新增历史层（内部 ID：`His`）：最佳中考分数 103 后解锁。
- 新增地理层（内部 ID：`Geo`）：最佳中考分数 119 后解锁。
- 历史 / 地理位于 row 0，与语文 / 数学 / 英语 / 政治同排；各有 Main、背诵专区和 Minigame I。
- 交叉联动：历史 ↔ 政治 / 语文，地理 ↔ 数学，历史 ↔ 地理互相提供全科倍率。
- 考试板块新增历史 / 地理试卷：单项选择题、材料解析题、综合题 / 材料分析题，题型参考天津中考。
- 历史 / 地理分数计入中考总分，两科都交卷后才能查分。
- 新增历史 / 地理成就页签。

## v0.3.0 政治

- 新增政治层（内部 ID：`Pol`，道德与法治），最佳中考分数 84 后解锁。
- 政治位于语文 / 数学 / 英语同排，是第四门主科。
- Main 显示政治能力和道德修养 / 法治意识 / 国情认知 / 时政敏感度 / 答题规范五项评分。
- 新增背诵专区：消耗政治能力，永久提高对应评分。
- 新增 Minigame I「时政速答」：30 秒政治选择题，答对 +3、答错 -1。
- 新增政治成就页签，并将政治评分接入全科知识获取。

## v0.2.0 体育（历史版本）

- 新增独立的 **体育层（PE）**：最佳中考 256 分解锁，复现身体数据表和 30 秒反应速度训练。
- 体育 Minigame I：30 道整数计算题，答对 +3、答错 -1，结束后提升体育能力与反应速度。
- 新增体育成就页签，并修复成就页报错。
- 物理层曾在此版本加入，已在 v0.8.0 删除；旧 Rebirth 原型仍保留在 `Old Things/rebirth-prototype.js`，不再加载。
