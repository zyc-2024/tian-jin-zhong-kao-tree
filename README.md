# 天津中考树：Story

《天津中考树》的 Story 更新。游戏以天津中考为背景，用增量/模组树的方式重走初中三年：语文、英语、数学理论、中考分数、经验、自动化与排行榜层层嵌套。

## v0.15.0 Story

- 新增「成长档案」页签，用 12 个章节串联成就剧情。
- 章节根据成就数量、考试分数、学科训练和综合素质进度逐步解锁。
- 为全部 300 个成就补充目标提示和完成后的剧情提示。
- 成就不再只是数字，完成时会对应到成长档案中的章节。
- 旧存档加载后会根据已有进度自动解锁对应章节。

## v0.14.0 300

- 成就总数扩充到 300 个。
- 新增理科训练、文科训练、学科能力、考试进阶、进阶收集五个成就页。
- 为物理 / 化学 / 生物 / 体育 / 政治 / 历史 / 地理增加训练次数、最佳分数和能力阈值成就。
- 为中考总分、历史考试、地理考试增加分数成就。
- 为里程碑收集、成就数量、15 组联动满级和层内进度增加成就。
- 旧存档会自动结算已经满足条件的新成就。

## v0.13.0 Links

- 训练收益接入跨学科联动：相关联动等级越高，训练获得的能力越多。
- 每个训练层 Main 显示当前跨学科训练加成。
- 新增体生联动，综合素质联动扩展到 15 组。
- 增加双向跨层反馈：体育 → 生物人体、政治 → 历史事件、历史 → 语文阅读、地理 → 生物生态。
- 物理 → 化学实验、化学 → 生物实验、生物 → 地理综合评分继续生效。
- 各训练层说明框同步标注新的跨层效果。

## 术语约定

- 树节点使用短标记：P = 物理，Chem = 化学，Bio = 生物，PE = 体育，H = 历史，G = 地理，Pol = 政治，Syn = 综合素质。
- 中文界面统一使用：物理、化学、生物、体育、历史、地理、政治、综合素质。
- 英文层名统一使用：Physics、Chemistry、Biology、Physical Education、History、Geography、Politics、Synergy。
- 内部层 ID 与存档字段仍为 `P`、`Chem`、`Bio`、`PE`、`His`、`Geo`、`Pol`、`Syn`，不随显示文本变化，旧存档可以继续读取。
